# 安装与常见问题

本文是 [README](../README.md) 安装章节的**详细版**：包含逐步说明、各厂商拦截的处理方法、故障排查顺序，以及数据备份建议。

---

## 一、系统要求

| 项 | 要求 |
| --- | --- |
| 系统版本 | Android 9.0（API 28）及以上 |
| CPU 架构 | arm64-v8a（近年主流手机均支持） |
| 存储空间 | 安装约 130 MB；如需下载本地检索模型，另需约 240 MB |
| 网络 | 配置模型需要；**首次启动与日常写作不需要联网** |

> 本项目**不包含任何模型**。模型由用户自备 API Key 接入，多数厂商提供免费额度。

---

## 二、下载

1. 打开仓库的 **Releases** 页面，进入最新版本
2. 在 **Assets** 中下载 `Storyloom-Android.apk`
3. **无需解压**，直接安装

### 核对下载完整性

如果安装时提示「软件包无效」「解析失败」等，先确认下载是否完整——对照 Release 上标注的文件大小（约 126 MiB / 133 MB，二者是同一数值的不同单位换算）。

### 核对安装包来源

本项目所有版本都使用**同一把固定证书**签名，SHA-256 指纹为：

```
EA:B4:3A:19:25:D9:B3:6D:6D:FB:2D:59:BD:40:A9:7C:24:FF:AB:D2:C6:07:12:00:50:62:68:56:73:07:68:E7
```

下载后可用任意 APK 信息查看工具核对指纹，确认安装包来源可信。

---

## 三、安装

1. 用手机上的文件管理器找到下载好的 APK，点击安装
2. 系统提示「未知来源」或安全风险时，选择**允许 / 继续安装**
3. 安装完成后桌面出现名为 **Storyloom** 的应用

### 可与官方版共存

本应用的包名为 `com.meeko529.storyloom`，与上游 OpenFicM 的包名不同，**两者可以同时安装、互不影响**。

### 从旧版本升级

- 自使用**固定签名**的版本起，后续版本可以直接覆盖安装，不需要卸载
- 如果你手机上的版本早于该版本（使用调试证书签名），**需要先卸载再安装一次**。卸载会清除应用数据，请先导出作品

---

## 四、被手机安全机制拦下怎么办

国产 ROM 对非应用商店来源的安装包普遍有安全提示。**这是系统行为，与安装包本身无关**，国产 ROM 上任何第三方 APK 都会遇到。

### 通用处理

安装被拦时，界面底部通常会提供**「继续安装」**（部分机型需要先点「更多」、或等待倒计时结束）。选择它即可继续。

### 分品牌说明

| 品牌 | 可能的提示 | 处理方式 |
| --- | --- | --- |
| **vivo / iQOO** | 「安装包缺乏开发者证书」「软件包似乎无效」 | 多为安全检测拦截。确认签名一致后重试；必要时关闭「设置 → 安全 → 更纯净 / 纯净模式」，或先卸载旧版本 |
| **小米 / Redmi** | 「安全检测未通过」 | 点击「继续安装」；如无该选项，在设置中关闭「纯净模式」 |
| **华为 / 荣耀** | 「应用未通过安全检测」 | 点击「继续安装」；或在「设置 → 安全 → 更多安全设置」中允许安装未知来源应用 |
| **OPPO / 一加 / realme** | 「未备案应用」提示 | 属于备案要求，个人项目无法消除，点继续安装即可 |
| **通用** | 安装按钮灰色或点击无反应 | 检查系统是否开启了「安装陌生应用」限制；换用系统自带文件管理器打开 APK |

### 关于应用备案

自 2023 年起，中国大陆要求移动应用完成备案。**本项目为开源项目、不在应用商店上架，无法也不计划完成备案**，因此部分机型会显示相关提示——这不影响安装成功后的正常使用。

## 五、首次启动

**首次启动不需要下载任何资源**，基础 Agent / Skill 内容包已内置于安装包中，打开即可使用。

如需语义检索、文风蒸馏等功能，可在 **设置 → 高级 → 可选内容** 中按需下载对应资源：

| 资源 | 用途 | 是否必需 |
| --- | --- | --- |
| 嵌入模型（约 15 MB） | 语义检索：搜到你以前写过的内容 | 否 |
| 重排模型（约 209 MB） | 让检索结果排序更准 | 否 |
| Lorn 文风 Skill | 从导入的参考小说中蒸馏文风 | 否 |
| oh-story 内容包 | 网文全流程进阶技能 | 否 |

下载时会自动尝试国内镜像，主源失败自动切换备用源。

## 六、配置模型

应用**不内置模型**，需要接入你自己的模型服务。

### 步骤

1. 打开 **设置 → 模型与供应商**
2. 在「常用服务商」中点选你的服务商（智谱 / DeepSeek / 通义千问 / 硅基流动 / Kimi）
   - 点选后会自动填好**显示名称**与 **Base URL**
   - 若使用中转站或自建网关，选择「中转站 / 自定义」，手动填写地址
3. 粘贴你的 **API Key**（在服务商官网注册后生成）
4. 点击 **保存供应商**
5. 在「添加模型」中填写：
   - **模型名称**：自定义显示名，随意填写
   - **模型 ID**：服务商文档中的模型标识，必须完全一致（例如智谱为 `glm-4.7-flash`）
6. 点击 **添加模型**，然后在模型列表中点选它，使其成为当前使用的模型

### 关于 function calling

助手的**读写能力**（读取章节、写入角色卡等）依赖模型的 function calling 支持。

- 支持工具调用的模型：助手功能完整
- 不支持工具调用的模型：助手只能对话，无法读写作品内容

选择模型时请留意服务商文档中的说明。

### 中转站 / 自建网关

如果服务商要求额外的请求头或非标准的鉴权方式，展开 **高级设置**：

| 设置项 | 用途 |
| --- | --- |
| 额外请求头 | 每行一条「名字: 值」，例如 `HTTP-Referer: https://example.com` |
| 鉴权请求头名字 | 默认 `Authorization`，部分服务使用 `api-key` |
| 鉴权前缀 | 默认 `Bearer `，留空则发送原始 Key |
| 不发送 tools | 极少数中转站不支持 function calling |
| 使用 `max_completion_tokens` | 个别供应商只接受该参数名 |

## 七、数据与备份

- 作品、章节、角色、世界书、索引与对话记录保存在**应用私有目录**的本地数据库中
- API Key 存放在系统安全存储，不写入数据库
- **除调用你配置的模型接口外，应用没有其他网络出口**

### 一键备份与恢复

「设置 → 高级 → 备份与恢复」提供整机数据备份：

- **导出备份**：把数据库（作品、卷章、笔记、草稿、智能体、技能、规则、设置）与文风库原文打包为 zip，通过系统分享保存到网盘、文件管理器或发送到电脑
- **从备份恢复**：选择备份文件 → 二次确认 → 覆盖本地数据 → **完全关闭并重新打开应用**后生效

备份**不包含** API Key（存于系统安全存储）与可重新下载的内容包资源，恢复后需重新填写 API Key。

### 重要：卸载会清除全部数据

卸载应用会**一并删除应用私有目录**，作品数据无法找回。因此：

1. 换机、重装或尝试新版本前，先执行上文的**一键备份**
2. 需要单纯导出文稿时，用应用内的**导出**功能把作品保存为 Markdown 文件
3. 导出的文件可以用任何网盘或 Git 仓库管理

## 八、应用内更新与诊断报告

### 应用内更新

「设置 → 高级 → 检查应用更新」可直接查看最新版本并下载安装，不必再回 GitHub 手动下载：

1. 点「检查应用更新」→ 显示最新版本与更新说明
2. 有新版本时点「下载并安装 X」，主源失败会自动尝试国内加速镜像
3. 下载完成后系统弹出安装界面，首次需授权「允许安装未知应用」

若仓库处于私有状态或网络不通，更新检查会失败——**这是预期行为，不影响已安装版本的使用**。

### 诊断报告

「设置 → 高级 → 导出诊断报告」会生成一份包含应用版本、设备信息与非敏感设置项的文本，通过系统分享发出。**不含 API Key，不含任何稿件内容**，适合反馈问题时一并附上。

## 九、故障排查顺序

安装或启动失败时，建议按以下顺序排查：

1. **核对文件大小**是否与 Release 标注一致（排除下载中断）
2. **确认已卸载旧版本**（仅当手机上装的是更早的调试签名版本）
3. **查看系统是否有「继续安装」选项**（排除安全机制拦截）
4. **检查存储空间**是否充足
5. **重启手机后重试**（部分机型需刷新安装服务状态）

若以上均无效，可在 Issues 中反馈，并附上：**手机型号、系统版本、完整提示文字、问题截图**，以及「高级」页导出的**诊断报告**。
