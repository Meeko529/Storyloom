# 界面截图

本目录用于存放 README 展示用的界面截图。

## 建议截图清单

| 文件名 | 内容 |
| --- | --- |
| `01-书架.png` | 书架页（作品列表） |
| `02-写作.png` | 写作页（编辑状态，可体现字号与字体效果） |
| `03-助手.png` | 助手页（含实时执行过程） |
| `04-供应商.png` | 设置 · 模型与供应商（含常用服务商按钮与高级设置） |
| `05-编辑器.png` | 设置 · 编辑器（字号输入 + 字体选择 + 预览） |
| `06-外观.png` | 外观主题设置（该功能完成后补充） |

## 添加方式

1. 手机截图后传到本目录
2. 在 [README](../README.md) 的「功能」章节顶部插入引用，例如：

```markdown
![书架](docs/screenshots/01-书架.png)
```

> 建议截图宽度统一（手机竖屏截图即可），并在截图前准备演示用的示例作品内容。
